# Kindeks (SwiftUI App) — как скачать и запустить

Инструкция для заказчика: запуск проекта на Mac и на своём iPhone.

## Что понадобится

- **Компьютер:** Mac с macOS (желательно актуальная версия).
- **Xcode** из App Store (версия с поддержкой **iOS 17.2+**; обычно Xcode 15.x или новее).
- **Apple ID** (бесплатного достаточно для установки на свой iPhone).
- **iPhone** с **iOS 17.2 или новее** — если нужен запуск на телефоне, а не только в симуляторе.

Разработка под iOS **с Windows/Linux не выполняется** — нужны Mac и Xcode.

## 1. Скачать проект

**Вариант A** — через терминал (если установлен Git):

```bash
git clone https://github.com/Pavel1970-code/SwiftUIApp.git
cd SwiftUIApp
```

**Вариант B** — в браузере: открыть [https://github.com/Pavel1970-code/SwiftUIApp](https://github.com/Pavel1970-code/SwiftUIApp), нажать **Code → Download ZIP**, распаковать архив.

## 2. Открыть проект в Xcode

1. Запустить **Xcode**.
2. **File → Open…** и выбрать файл **`SwiftUI App.xcodeproj`** внутри папки проекта (именно этот файл, не произвольную папку).

Дождаться окончания индексации проекта (прогресс в строке состояния Xcode).

## 3. Подпись приложения (Signing) — нужно для установки на телефон

1. В навигаторе слева нажать на **синюю иконку проекта** (корень).
2. Выбрать таргет **SwiftUI App**.
3. Вкладка **Signing & Capabilities**.
4. Включить **Automatically manage signing**.
5. В поле **Team** выбрать свою команду. Если списка нет: **Xcode → Settings → Accounts → +** и войти под **Apple ID**.

Если Xcode сообщает, что **Bundle Identifier** занят, в том же разделе измените его на уникальный, например `com.вашафамилия.kindeks` (латиница, без пробелов).

## 4. Запуск в симуляторе iPhone (на Mac)

1. В панели Xcode рядом с кнопкой запуска выбрать **iPhone Simulator** (например, iPhone 15).
2. Нажать **Run** (▶) или **⌘R**.

Приложение откроется в **Simulator**. Интерфейс со «стеклянными» эффектами в симуляторе может работать **менее плавно**, чем на реальном устройстве — это нормально.

## 5. Запуск на своём iPhone

1. Подключить iPhone кабелем, разблокировать, при запросе выбрать **Доверять этому компьютеру**.
2. В Xcode в списке схемы/устройств выбрать **ваш iPhone** (не Simulator).
3. Нажать **Run** (▶).

**Первый запуск на устройстве:** на iPhone открыть **Настройки → Основные → VPN и управление устройством** (в старых версиях: **Профили и управление устройством**) → профиль разработчика → **Доверять**.

Ограничения **бесплатного** Apple ID (срок действия профиля, число приложений и т.д.) задаёт Apple. Для долгой установки без пересборки обычно используют **Apple Developer Program** (платная подписка) или распространение через **TestFlight** / **App Store**.

## 6. Bluetooth и симулятор

**Bluetooth (BLE)** в симуляторе **ограничен**. Чтобы проверить обмен между участниками, надёжнее использовать **два реальных iPhone** (или iPhone и второй тестовый девайс) с установленной сборкой и разрешениями Bluetooth.

## 7. Если сборка не проходит

- Обновить **Xcode** и при необходимости **macOS**.
- В Xcode: **Product → Clean Build Folder** (зажать **Option** при меню **Product**), затем снова **Run**.
- Убедиться, что открыт **`SwiftUI App.xcodeproj`**, а не копия папки без проекта.
